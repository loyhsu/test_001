# 抠图与换背景：摸头模板首版设计

**状态：** 已确认  
**范围：** 仅打通“摸头”模板的端到端流程

## 用户目标

用户选择一张人物或宠物照片后，能看到抠出的真实主体，拖动/缩放主体、选择背景，并在生成 GIF 前确认合成效果。编辑器预览和最终 GIF 必须使用相同的主体、背景与编辑参数。

## 主流程

```text
选择照片
→ 私有上传并做内容安全检查
→ 复用现有服务端抠图，生成透明主体临时图
→ 编辑器显示主体 + 背景 + 摸头动效预览
→ 用户拖动/缩放主体并选择背景
→ 生成器使用同一主体、背景和参数输出 GIF
→ 结果页沿用现有保存/分享流程
```

抠图期间显示明确的处理中状态。抠图失败时保留原照片，提供重试和换照片；不允许以未抠图的原照片伪装成功，也不允许继续生成。

## 编辑器行为

- 主体使用服务端返回的透明 PNG，而不是原图；画布的初始主体尺寸、中心点和缩放映射须与生成器一致。
- 继续支持拖动、缩放和三档动图速度。
- 背景首版提供：模板原背景（默认）、浅蓝 `#DCEEFF`、奶油杏 `#FFF0DC`、淡紫 `#EFEAFF`。前后端使用相同的稳定背景 ID 和颜色映射，并用测试防止映射漂移，保证预览和 GIF 一致。
- 背景选择、主体位置、缩放、速度都进入编辑状态并传到生成端；不增加手动擦边/修复工具，也不支持上传自定义背景。
- 本轮只承诺摸头模板可完整生成；其他模板的素材和可生成性保持现状，不扩展本轮范围。

## 服务端与隐私

- 图片仍走现有 CloudBase 私有上传、内容安全和生成服务；客户端不直接调用抠图模型，也不获得永久公开地址。
- 上传凭证绑定微信用户、请求 ID 和源文件路径。抠图服务返回的透明图写入私有临时存储；编辑预览仅使用短期临时 URL。凭证未完成抠图时沿用现有短有效期；抠图成功后源图和透明图按成功时间起算 24 小时到期。
- 已用于生成的文件转由作品记录和既有到期清理管理；未生成的过期上传凭证由清理任务删除其源图、透明图和凭证记录。当前清理按小时运行，正常情况下到期后实际删除延迟小于 1 小时；任务故障或积压时可能更久，不能承诺严格的物理删除上限。
- 最终 GIF 复用已抠透明图，避免再次抠图；作品仍只对所有者可见。
- 同步更新隐私数据流说明，明确预览前上传、临时抠图和过期清理。

## 验收条件

1. 合法照片经内容安全检查和抠图后，编辑器能显示透明主体；拖动、缩放、速度和四种背景选择均可操作。
2. 生成后的 GIF 与编辑器使用相同背景 ID，主体位置/大小及速度与编辑设置一致。
3. 未授权用户、错误/过期上传凭证、超限或不合规照片不能取得抠图结果或生成作品。
4. 抠图或网络失败时给出可恢复提示，不丢失已选照片；未完成的临时文件能在到期清理中删除。
5. 摸头模板通过本地自动化验证；其他模板未被标记为已打通。

## 本轮不处理

- 其他五个模板的素材补齐。
- 手动抠图修边、用户上传背景、会员/支付/广告。
- 微信平台是否允许小程序直接把 GIF 写入用户表情收藏；这是产品“最后一公里”的独立验收项，本轮不作平台能力承诺。
